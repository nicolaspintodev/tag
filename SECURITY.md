# Seguridad

## Reportar vulnerabilidades

No abrir un issue público para vulnerabilidades. Escribir a **nicolaspinto2805@gmail.com** con:

- Descripción del problema.
- Pasos para reproducirlo.
- Impacto estimado.
- Versión o commit afectado.

Se responderá a la brevedad posible.

## Datos sensibles

No subir al repositorio:

- Archivos `.env` ni credenciales.
- Bases de datos SQLite/MySQL con datos reales.
- Documentos, remitos o cartas de porte de clientes.
- Tokens de GitHub, DonWeb o cualquier servicio externo.

## Alcance

Este proyecto es una PoC. La autenticación y la facturación todavía no están completas; no debe exponerse con datos reales hasta completar esos módulos.
